# Beispiel: Übungs-Repository aus Teil 1

Die Lösungsdateien zu den Aufgaben 1–5 aus [Readme.md](../Readme.md) – im **Endstand**.

| Datei                                                        | Aus Aufgabe |
| ------------------------------------------------------------ | ----------- |
| [.github/workflows/hallo.yml](./.github/workflows/hallo.yml)       | 1           |
| [.github/workflows/events.yml](./.github/workflows/events.yml)     | 2           |
| [.github/workflows/pipeline.yml](./.github/workflows/pipeline.yml) | 3           |
| [.github/workflows/test.yml](./.github/workflows/test.yml)         | 4 und 5     |
| [index.html](./index.html), [test.sh](./test.sh)             | 4           |
| [Dockerfile](./Dockerfile)                                   | 5           |

> **Wichtig:** GitHub führt Workflows **nur** aus, wenn der Ordner `.github/workflows/` im **Hauptordner** eines Repositories liegt. Kopiere den Inhalt dieses Ordners in dein eigenes Repository `ci-cd-uebung`.
